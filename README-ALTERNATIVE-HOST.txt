Cricket Stats — Alternative Hosting Package

This package is independent of Netlify hosting.
The website files can be hosted on GitHub Pages, Cloudflare Pages, or another static web host.

Important:
- The Google Apps Script backend URL already used by the website is kept unchanged.
- Do NOT publish the Google Sheet itself.
- The Admin PIN remains configured in Code.gs.
- For GitHub Pages: upload index.html and 404.html to the repository root, then enable Pages from Settings > Pages.
- For Cloudflare Pages: upload/deploy the contents of this folder as a static site.

The existing Google Apps Script backend is separate from Netlify, so changing the website host does not by itself require changing the backend.
